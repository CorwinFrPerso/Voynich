# Gallows, rails et opérateurs graphiques

## Correction méthodologique

Ne pas traiter le `rail` comme un opérateur universel présent partout.

Structures à distinguer :

1. `cc + rail` : deux formes c reliées au niveau supérieur.
2. `c + gallow + c` avec rail global : le rail est porté par les c et traverse/intersecte les jambes du gallow.
3. formes longues / split gallows : cas exceptionnels à analyser séparément.

Le bench peut être un **cadre graphique local** plutôt qu'une lettre ou un opérateur indépendant.

## Relations gallows

Hypothèse structurale :

- `p = f + boucle gauche`
- `t = k + boucle gauche`
- familles une hampe / deux hampes
- présence/absence de bench comme dimension supplémentaire possible

Si ces ajouts sont fonctionnels, leur effet statistique doit être partiellement régulier d'une base à l'autre.

Test clé : comparer l'effet contextuel de `f→p` avec celui de `k→t`.

## f8r et formes longues

Observation de Guillaume sur f8r :

- deux groupes visuellement séparés semblent reliés par une structure ressemblant à un gallow à deux branches ;
- branche gauche ancrée sur une structure de type `cc + rail + o` ;
- branche droite ancrée sur une structure de type `cc + rail + c + g` ;
- les jambes du grand signe semblent interagir avec les rails.

Question centrale :

> S'agit-il réellement d'un gallow atomique étiré, ou de traits/boucles opérateurs qui, lorsqu'ils relient plusieurs chunks, prennent la forme d'un gallow ?

## Hypothèse de portée / factorisation

Modèle conceptuel :

```text
       ┌──── opérateur commun ────┐
       A                          B
```

Une information commune pourrait être écrite une seule fois et appliquée à plusieurs unités.

Cela pourrait factoriser :

- quantité commune ;
- instruction commune ;
- terminaison commune ;
- classe morphologique commune ;
- relation grammaticale commune ;
- information vocalique/syllabique commune.

Dans ce modèle, un espace sous un pont graphique ne serait pas nécessairement une frontière de mot en clair.

## Pourquoi les formes longues seraient rares

Si elles correspondent à une portée ou factorisation, elles n'apparaîtraient que lorsque deux unités doivent partager une information. Cela explique leur rareté sans créer un alphabet spécial de glyphes géants.

## Inventaire à construire

Pour chaque long/split gallow :

1. folio et ligne ;
2. forme de la jambe gauche ;
3. point d'ancrage gauche ;
4. forme de la jambe droite ;
5. point d'ancrage droit ;
6. éléments sous le pont ;
7. espaces traversés ;
8. équivalent possible des deux moitiés parmi `f/p/k/t` ;
9. segmentation EVA ;
10. segmentation v101 ;
11. confiance visuelle R0/R1/R2.

## Critère de validation

L'hypothèse devient forte si les formes longues se reconstruisent avec les **mêmes primitives robustes** que les gallows normaux et si leur contexte montre une propriété commune aux éléments reliés.

Si chaque forme longue exige une règle différente, abandonner cette piste.
